# Security policy

Do not report security problems in public issues. Follow the organization's
[security policy](https://github.com/rathkit/.github/blob/main/SECURITY.md).

**Scope.** This repository runs third-party tools offline, in a throwaway container, against a read-only
Pack binary. Report a problem with the recipe here (for example a way out of the container, or a step that
runs untrusted code with network access). Report a problem in a compared tool to that tool's own project.
